# Migrazione R4a → R4b

R4b aggiunge una nuova opzione di export in R2:

- `Mirror laterale`

Il valore viene memorizzato anche nei profili persistenti di allineamento.

Con mirror attivo, l'export crea una seconda direzione specchiata e produce file aggiuntivi:

- frame della direzione opposta;
- spritesheet della direzione opposta;
- manifest della direzione opposta.
