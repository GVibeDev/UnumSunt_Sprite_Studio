# Migrazione R5e11 → R5e12

R5e12 è una milestone di consolidamento UI. Non modifica i dati produttivi del Character Set né la pipeline di generazione/elaborazione.

## Cambiamenti visibili

- menu tradizionale applicazione;
- toolbar contestuale;
- tab principali abbreviate e colorate con progressione dark→light;
- workspace Genera suddiviso in sottopagine responsivi;
- Job/Output separato dalla cronologia.

## Shortcut

```text
Ctrl+N        Nuovo progetto
Ctrl+O        Apri progetto
Ctrl+S        Salva progetto
Ctrl+Shift+O  Apri video
Ctrl+Alt+O    Apri spritesheet
Ctrl+Shift+E  Export R1
```

Le shortcut di playback/selezione R1 sono attive soltanto nel workspace Estrazione.

## Compatibilità

I progetti precedenti vengono caricati e migrati allo schema R5e12 senza alterare workflow, layer o asset.
