# Migrazione R1a → R2a

R2a non richiede conversione di dati o cartelle.

La scheda **Estrazione R1** mantiene il comportamento validato. La selezione dei
frame viene trasferita in memoria alla scheda **Allineamento R2**.

Quando cambiano:

- frame selezionati;
- colore dello sfondo;
- tolleranza;
- morbidezza;
- pulizia;
- decontaminazione;

R2 viene marcata come non aggiornata. È necessario premere di nuovo
**Aggiorna dai frame R1**. Questa scelta evita di usare in silenzio sagome
obsolete e impedisce esportazioni incoerenti.
